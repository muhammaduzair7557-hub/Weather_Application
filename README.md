# Weather App

A web app that fetches real-time weather data for any city using the OpenWeatherMap API.

## Features
- Search weather by city name
- Displays temperature, humidity, and weather condition
- Responsive design for mobile and desktop

## Tech Stack
HTML · CSS · JavaScript · OpenWeatherMap API

## How to Run
Visit the live demo: https://github.com/muhammaduzair7557-hub/Weather_Application

Or clone the repo and open with a local server:
- VS Code: use the Live Server extension
